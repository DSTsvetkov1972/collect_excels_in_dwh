Если нужно начать проект заново,
удалите из базы данных progress_all 
соответствующую проекту таблицу
и соответствующие таблицы в хранилищах

Если нужно только заново загрузить 
файл эксель в в DWH, удалите соответствующую ему строку
в соответствующей таблице progress бд progress_all.db.

Если нужно загрузить новый файл в DWH,
добавьте его в папку sources проекта.

По умолчанию первая строка csv файла сразу содержит данные,
если это не так задайте номер строки заголовка через параметр
if_csv_source_header в файле config.json

По умолчанию первая строка excel файла содержит заголовок,
если это не так задайте номер строки заголовка через параметр
if_csv_source_header в файле config.json
